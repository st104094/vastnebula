# VastNebula DJ Platform

赛博朋克电音视觉的 DJ 音乐网站静态原型，适合直接部署到 GitHub Pages。

## 功能

- 沉浸式 Hero 区和霓虹动态网格背景
- 中英双语切换
- Night / Day / Auto 三态主题
- 移动端侧滑导航
- 首页活动 Banner
- 音乐库 BPM、Key、流派筛选和列表/网格切换
- 全局播放器、购物车计数、Toast 状态反馈
- NJ 电台、直播、商城、调音师和社区热帖模块
- 社区热帖已接入封面缩略图

## 预览

直接打开 `index.html` 即可预览。

## GitHub Pages

在仓库 Settings -> Pages 中选择 `main` 分支根目录发布。
